# AI Use

- Antigravity CLI / Gemini is used optionally to expand a topic into narration scenes.
- If Antigravity is unavailable or times out, the service uses the deterministic local generator in `incubrix/script_generator.py`.
- AI-generated or provider-generated media is represented in the output manifest; the default fallback uses internal developer plates.
- Coding assistance was used to inspect, test, and update this repository. No secrets or private tokens are committed.
