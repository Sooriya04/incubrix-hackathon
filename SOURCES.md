# Sources

- Remotion 4 and React: local video composition and rendering.
- FastAPI, Pydantic, HTTPX, aiofiles: local API and service runtime.
- FFmpeg and ffprobe: audio/video assembly and output validation.
- espeak-ng and edge-tts fallback path: local narration synthesis.
- Pixabay: optional stock-footage provider, enabled with `PIXABAY_API_KEY`.
- Antigravity CLI / Gemini: optional script generation provider, enabled by a local authenticated `agy` session.
- Internal developer plates: deterministic fallback visuals used when no commercial stock clip is available.

Provider rights and attribution are recorded in each generated `timeline.json` and `manifest.json`.
